# Профили жюри: ожидаемые свойства

Все пять профилей синтетические. Загружать `employees.json` и `activity_history.csv` вместе через HR или `python scripts/eval_profiles.py`. Скрипт использует только публичный HTTP API, не импортирует движок. Исходные E-профили не изменяет и глобальный reset не вызывает. Повторный запуск обновляет T-профили; тестировать лучше в отдельном демо-процессе.

| Профиль | Ловушка | Проверяемое свойство |
|---|---|---|
| T001 | Public Speaking = 0, три no-show; цель Senior с критическим System Design | Первый шаг закрывает критический навык, а не только самый низкий; в плане ≥3 вида факторов и объяснение альтернатив |
| T002 | Курс завершён 15 сентября после оценки 1 сентября | Эффективные навыки включают прирост с ограничением max_level; завершённое нерегулярное мероприятие не повторяется |
| T003 | System Design = 0, продвинутые занятия требуют минимум 2 | Первый шаг доступен сразу; последующие пререквизиты проверяются после симуляции предыдущих шагов |
| T004 | Remote, полезные занятия есть офлайн | Если офлайн выбран, в факторах есть штраф work_format −0.8. Это мягкий штраф, не запрет: обоснованный офлайн допустим |
| T005 | Lead, все 60 навыков = 5, цели нет | Готовность 100%, пустой план с непустой причиной; модель не выдумывает шаг |

Общие проверки: максимум три уникальных шага, мероприятия существуют, добровольные, подходят роли/грейду, имеют доступную сессию либо self-paced; пререквизиты и прирост соответствуют каталогу; объяснения непустые; HTTP-ответ ≤10 секунд. Не требуем конкретный event_id или неизменный порядок.

```bash
python scripts/eval_profiles.py
python scripts/eval_profiles.py --base-url http://127.0.0.1:8001 --output docs/verification/eval.json
python scripts/eval_profiles.py --require-llm
```

Код возврата: 0 — все свойства выполнены; 1 — найдено нарушение; 2 — ошибка API/импорта. `--require-llm` требует реальный LLM для T001–T004; T005 не нуждается в вызове модели. Без этого флага PASS подтверждает корректность свойств, но не факт использования OpenAI. Семантическое качество объяснений, язык и убедительность аргументов оцениваются человеком отдельно.
