## Проверенные проблемы

1. `backend/app/services/store.py:103`: CSV удаляет старую историю до проверки новых записей. Импорт строки с UNKNOWN event для E0001 вернул 200 и уменьшил историю с 7 записей до 0. Нужна атомарная валидация до изменения хранилища.
2. `backend/app/services/engine.py:537`: complete не проверяет доступность курса. E0001 может завершить EV_006, отклоняемый eligibility по audience, и получить рост навыков. Проверять audience, prerequisites и остальные ограничения перед записью.
3. UI вызывает POST feedback, которого нет на backend; проверка вернула 405. Реализовать сохранение отказа и пересчёт либо убрать кнопку до готовности API.
4. `frontend/src/api/client.ts:33`: адаптер теряет source/model/latency_ms. Интерфейс должен явно отличать LLM от fallback.
5. `frontend/src/pages/EmployeePage.tsx`: trace показывает имя шага вместо detail; история повторно разворачивается и показывает старые записи первыми.
6. Агент сейчас делает один структурированный LLM-вызов после расчётов Python. Настоящий цикл выбора инструментов моделью ещё TODO. Не представлять анимацию загрузки как реальные вызовы инструментов.

Дополнительные ограничения: данные main в памяти теряются после перезапуска; роль доверяется заголовкам клиента, это демонстрационная авторизация. README main содержит только имена и не объясняет запуск.
