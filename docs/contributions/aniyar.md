# Aniyar Baibossyn

## Основа проекта, созданная совместно с Codex
- Выбор архитектуры и распределение независимых зон трём участникам.
- Контракты API/agent и задания для Azamat и Umar.
- Store/SQLite, правила расчёта навыков и кандидатов, симуляция, история, импорт.
- FastAPI, серверное разделение ролей employee/HR, базовый работающий React-интерфейс.
- Тесты предметных правил и API, CI, локальный/Docker-запуск.

## Проверка
- `python run.py --setup`: зависимости установлены в чистую .venv, UI собран, сервер запущен.
- `python -m pytest -q`: проверки backend проходят; повторно проверены в .venv с закреплёнными зависимостями.
- `npm --prefix frontend run build`: TypeScript и production-сборка проходят.
- Браузер: вход E0001 → подбор → завершение System Design Fundamentals → покрытие цели 54,5% → 60,6%.
- При установке обнаружена уязвимость старого Vite; версия обновлена в пределах major 7, npm сообщил 0 vulnerabilities.

AI-подбор пока не реализован: это отдельная зона Umar. UI служит рабочей базой для улучшений Azamat. Docker-образ не запускался.
