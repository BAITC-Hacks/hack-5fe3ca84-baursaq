# Aniyar Baibossyn — платформа и проверка

Работа выполнена с Codex; коммиты содержат `[codex]` и сделаны под настроенной Git-подписью участника.

- `eceb935`: Docker multi-stage, compose, исключение секретов и локальных артефактов, launcher на uv/npm с lock-файлами.
- `41cd2a7`: пять синтетических профилей жюри и независимый HTTP eval ожидаемых свойств.
- README: запуск, фактические режимы агента, веса, API, ограничения и сценарий демонстрации.
- Проверки: Docker из чистого клона, локальный launcher, тесты backend и eval. Подробности — [протокол](../verification/README.md).

Первая ветка foundation была отдельным прототипом. Её целиком не сливали: итоговая упаковка адаптирована к общей архитектуре main. Backend/app и frontend/src в этой задаче не изменялись.
