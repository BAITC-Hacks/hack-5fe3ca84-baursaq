## Задача по приоритету (≈60 мин)
1. **ИИ или резерв — видно сразу.** Сохрани `source`, `model`, `latency_ms`, `summary` в `view.ts`/`client.ts`.
   Бейдж: `AI · gpt-6-luna · 4.2 с` (зелёный) или `Резервный режим — объяснение от движка` (янтарный).
   `summary` — строкой над карточками.
2. **Trace.** «Как агент пришёл к решению» — список реальных шагов из ответа: `step`, `detail`, `ms`.
   Шаги вида `llm→simulate_plan` (появятся у Азамата) выделять иконкой «инструмент».
   Анимация ожидания — просто «Агент анализирует профиль…», без фейковых номеров шагов.
3. **«Почему не другой шаг?»** — список карточек (название + причина), не один абзац через «;».
4. **«Не сейчас»** → тост «Шаг скрыт — история участия не изменена» и перезапрос рекомендаций.
5. **HR:** подписи графика не слипаются (перенос по словам); в таблице участия обязательные мероприятия
   помечены бейджем и по умолчанию скрыты фильтром «только добровольные»; после загрузки файлов —
   список добавленных `employee_ids` ссылками (открыть профиль) и `warnings`.
6. Сотрудник по умолчанию — **E0072** (лучший демо-профиль: 3 шага, готовность 53% → 67%).
7. Полировка: loading / error / пусто, ширина телефона без горизонтального скролла, никаких рейтингов.
