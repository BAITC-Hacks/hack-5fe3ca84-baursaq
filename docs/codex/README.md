# Использование Codex

Проверяемые свидетельства: Git-коммиты участников с `[codex]`, файлы задания в `docs/tasks/`, команды и результаты в `docs/verification/`.

Скриншоты самих сессий Codex ещё должны добавить участники. Для каждого снимка показать задание, фрагмент выполненной работы и результат проверки. Не включать API-ключи, `.env`, токены, содержимое менеджера паролей. Не выдавать снимок приложения за доказательство сессии Codex.

Рекомендуемые имена: `aniyar-session.png`, `azamat-session.png`, `umar-session.png`. Ссылки на изображения добавляются только после появления реальных файлов.
